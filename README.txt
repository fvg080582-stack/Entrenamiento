MI ENTRENAMIENTO · PWA

Archivos: index.html, app.js, manifest.webmanifest, sw.js e iconos PNG.

PUBLICACIÓN CON GITHUB PAGES
1. Crea un repositorio nuevo, por ejemplo: mi-entrenamiento.
2. Sube TODOS los archivos de esta carpeta al directorio raíz del repositorio.
3. GitHub: Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
4. Espera a que GitHub publique la URL.
5. Abre esa URL en Safari del iPhone.
6. Safari → Compartir → Agregar a Inicio → activa “Abrir como app web” → Agregar.

La app guarda el seguimiento localmente en el dispositivo mediante localStorage y puede funcionar offline una vez cargada. El botón “Exportar datos” permite guardar una copia JSON.
